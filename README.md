# 영상 자동 편집

영상을 올리면 **대본을 인식**해서

1. **컷 편집 1차** — 무음 구간 제거 + 필러워드("어", "음", "으음" …) 컷
   (쉼 0.4초까지는 자연스러운 호흡으로 남기고, 컷 지점은 가장 조용한 곳에 맞춰 툭 끊기지 않게 함)
2. **싱크 자막** — 잘린 타임라인에 맞춰 단어 단위로 자막 생성 → 영상에 입히기 + `.srt` 저장
3. **개인정보 처리**
   - 화면: 전화번호·이메일·주민번호·카드/계좌번호·차량번호·주소·"이름/주소/연락처:" 같은 라벨 뒤 값 → OCR로 찾아 모자이크 (움직이는 글자도 따라감)
   - 음성: 말로 말한 전화번호 등 → 삐 처리 + 자막 `***` 가림
   - 선택: 모든 얼굴 모자이크(실험적)

## 사용법

| 방법 | 하는 법 |
|---|---|
| 웹 화면 | `run_ui.bat` 더블클릭 → 브라우저에서 영상 업로드 → **편집 시작** |
| 끌어다 놓기 | 영상 파일(여러 개 가능)을 `drop_video_here.bat` 위에 드래그 |
| 명령줄 | `.venv\Scripts\python.exe main.py 영상.mp4 --aggressive --max-pause 0.3` |

결과는 `output` 폴더에 저장됩니다: `*_편집본.mp4`, `*_자막.srt`, `*_대본.txt`, `*_리포트.txt`

처음 실행할 때 음성 인식 모델(약 3GB)과 OCR 모델을 자동으로 받습니다.

## 자막 위치를 마우스로 지정하기

웹 화면(`run_ui.bat`)에서 영상을 올리면 **자막** 칸에 영상의 한 장면이 미리보기로 나타납니다.

- 자막을 놓고 싶은 곳을 **클릭**하면 그 점이 자막의 가운데가 되고, 샘플 자막이 바로 그 자리에 표시됩니다. (붉은 십자 = 지정한 점)
- **위쪽 / 가운데 / 아래(기본)** 버튼으로 빠르게 옮길 수 있습니다.
- 자막 크기를 바꾸면 미리보기도 같이 바뀝니다.
- 화면 가장자리를 클릭해도 글자가 잘리지 않게 자동으로 안쪽으로 보정됩니다.
- 명령줄에서는 `--sub-pos 가로,세로`(화면 비율 0~1)로 지정합니다. 예: `--sub-pos 0.5,0.15` = 가로 가운데·위쪽

## 자주 바꾸는 옵션

- **덜 자르고 싶을 때**: 유지할 쉼 길이 ↑ (`--max-pause 0.6`)
- **더 타이트하게**: 쉼 길이 ↓ + "그…/저…/아…" 제거 켜기 (`--aggressive`)
- **자막만 따로 올릴 때**: "영상에 자막 입히기" 끄기 (`--srt-only`) → SRT만 유튜브에 업로드
- **자막 폰트**: `--font-file 폰트.ttf`, 크기는 `--font-scale 1.2`
- **화면이 빠르게 움직이는 영상**: 화면 검사 간격 ↓ (`--ocr-interval 0.25`)
- **빠른 처리**: 모델을 `large-v3-turbo`로

## 참고 / 한계

- 같은 영상을 다시 돌리면 `work/` 폴더의 대본을 재사용해서 빠릅니다. 대본을 새로 인식하려면 해당 폴더의 `transcript.json`을 지우세요.
- Whisper는 "어/음"을 가끔 받아적지 않고 건너뜁니다. 그런 필러 중 앞뒤에 무음이 있는 것은 무음 컷에서 함께 정리되지만, 말 사이에 바짝 붙은 필러는 남을 수 있습니다.
- 개인정보 탐지는 패턴(정규식) + OCR 기반이라 **100%가 아닙니다.** 손글씨, 아주 작은 글씨, 배경과 대비가 낮은 글씨는 놓칠 수 있으니 업로드 전에 `리포트.txt`의 시간대를 한 번 확인하세요. 사람 이름만 단독으로 나오는 경우(라벨 없이)는 잡지 않습니다.
- 말로 한 주소·이름은 자동으로 거르지 않습니다(숫자형 정보만 삐 처리).
